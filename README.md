# 📞 Telecom Customer Churn Analysis

## 📊 Project Overview  
The **Telecom Customer Churn Analysis** project focuses on identifying patterns and factors influencing customer churn in the telecom industry.  
Using **Python for Exploratory Data Analysis (EDA)** and **Power BI for Visualization**, the project uncovers insights that help reduce churn rates, improve customer retention, and support data-driven business strategies.

## 🎯 Objectives  
- Analyze **customer demographics and service usage** to identify churn patterns.  
- Determine **key drivers of churn**, including tenure, contract type, and service combinations.  
- Build **interactive dashboards** to visualize churn metrics, customer lifetime value (CLV), and service preferences.  
- Provide actionable recommendations for **retention and engagement strategies**.

## 🧪 Data Processing & Methodology  

### 1. Data Cleaning  
- Removed null, duplicate, and inconsistent records.  
- Encoded categorical variables for model readiness.  
- Handled outliers using quantile-based trimming.  

### 2. Exploratory Data Analysis (EDA)  
- Used **Python** for deep-dive analytics into churn behavior.  
- Identified patterns across **tenure**, **contract type**, **monthly charges**, and **internet service**.  
- Visualized churn proportions using **Matplotlib** and **Seaborn** for pattern identification.  

### 3. Power BI Visualization  
- Integrated processed data into Power BI.  
- Designed **interactive churn dashboards** with:  
  - Churn segmentation by gender, contract type, and payment method.  
  - Monthly trend of churn rate.  
  - Customer distribution by service categories and total charges.  

---

## 📈 Dashboard Features  

### 📋 **1. Overview Dashboard**
- Displays **total customers**, **active customers**, and **churned customers**.  
- Highlights churn % and key KPIs across the customer base.  

### 🧍‍♂️ **2. Customer Profile Dashboard**
- Segments customers by **age group**, **gender**, and **tenure**.  
- Correlates service usage patterns with churn probability.  

### 💰 **3. Financial Impact Dashboard**
- Displays **average monthly charges**, **total revenue loss from churn**, and **contract-based comparisons**.  
- Visualizes how **contract type** affects churn behavior.  

### 📡 **4. Service Correlation Dashboard**
- Compares churn rate across **Internet Service**, **Streaming**, and **Tech Support**.  
- Highlights service combinations with the highest churn risk.  

---

## 🔍 Key Insights  

- Customers with **month-to-month contracts** show the **highest churn rate (~43%)**.  
- **Fiber optic internet users** are **twice as likely to churn** compared to DSL customers.  
- **Senior citizens** and **low-tenure customers** contribute the most to total churn.  
- Providing **long-term contracts** and **bundled service packages** could reduce churn significantly.

## 🚀 Outcomes  

- Delivered insights that can reduce **customer churn by 25–30%** with targeted retention offers.  
- Automated churn tracking using Power BI to reduce manual analysis time.  
- Enhanced understanding of **customer behavior**, enabling **data-driven retention strategies**.
